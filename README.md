# smartareng.ee — сайт v1.02 (вариант «Хром»)

Сайт MTÜ Smart Areng: обучение ИИ для команд малого и среднего бизнеса. Клиент собирает программу из модулей, видит часы и цену и скачивает ценовое предложение в PDF.

**Макет:** https://boxx1.github.io/SMARTARENG.EE_v1.02/

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `MAKET.md` | карта страницы: блоки по порядку, где что стоит, какие ключи текстов |
| `content/` | **все тексты сайта** в Markdown, по ключам и с лимитами знаков |
| `content/00-style.md` | правила тона, словарь, запреты — читать первым |
| `content/01-interface.md` | шапка, первый экран, конструктор, окна, сообщения формы, подвал |
| `content/02-modules.md` | 12 модулей обучения |
| `content/03-blocks-pdf.md` | полоса «Команда / Преподаватель» и тексты PDF |
| `content/04-organizer.md` | реквизиты, контакты, ставка — только подтверждённые данные |
| `docs/` | собранный макет для GitHub Pages: `index.html` уже содержит весь текст |
| `design/` | исходные файлы макета из Claude Design (`*.dc.html`) |
| `tools/` | скрипты сборки макета и выгрузки текстов |

## Как работаем с текстами

1. Редактор берёт файл из `content/` и правит текст под ключом, держа лимит знаков и правила из `00-style.md`. Редактор — Claude, ChatGPT или человек.
2. Владелец выбирает вариант, статус ключа меняется на `утверждено`.
3. Claude переносит утверждённые тексты в макет: в `design/`, затем собирает `docs/` и проверяет, что всё влезает.
4. Перед публикацией — отдельная проверка фактов: часы и цены, никаких обещаний финансирования, только подтверждённые реквизиты.

Ключи (`### hero.title · до 18 · черновик`) и подстановки `{…}` не менять: по ним текст попадает на место.

Дайте ему ссылки:

- тексты: https://github.com/boxx1/SMARTARENG.EE_v1.02/tree/main/content

Просите возвращать файл целиком в том же формате или только изменённые ключи.

## Сборка макета

```
node tools/export/build.js            # design/*.dc.html → docs/index.html
node tools/content/modules_to_md.js   # разовая выгрузка модулей в content/02-modules.md
```

Основная версия дизайна живёт на холсте Claude Design; `design/` — её копия на момент сборки.
