# Тексты интерфейса

Все надписи страницы, кроме модулей (`02-modules.md`), полосы «Команда / Преподаватель», PDF (`03-blocks-pdf.md`) и реквизитов (`04-organizer.md`).

Формат записи: `### ключ · лимит · статус`, ниже — текст. Ключ не меняем: по нему текст попадает на своё место. Лимит в знаках с пробелами посчитан по вёрстке; длиннее — ломает строку или кнопку.
Статусы: `черновик` → `на правке` → `утверждено`. Где ведущая ПРОПИСНЫМИ — так задумано в дизайне, писать можно обычным регистром, вёрстка сама переведёт в прописные.
`{…}` — подставляется автоматически (часы, цена, число модулей), трогать нельзя.
